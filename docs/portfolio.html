1왜 만들었나요?

전세사기 뉴스가 이어지면서 "이 집, 보증보험 가입이 되는 집인가?"를 먼저 확인하는 사람이 많아졌습니다. 하지만 기존 부동산 앱에서는 이 정보가 잘 보이지 않습니다. Safe Home은 HUG(주택도시보증공사) · HF(한국주택금융공사) 인증 여부를 매물 카드 맨 앞에 보여주는 것을 목표로 만들었습니다.

4주요 기능

메인 — 인증 매물만 골라 보여주기

  • Supabase에서 매물을 불러와 hug_mark · hf_mark가 true인 것만 Swiper로 노출
  • 건물 유형별 바로가기, 카카오맵 매물 카드

시장 — 지도와 목록 동시 탐색

  • 아파트 · 빌라/투룸 · 원룸 · 상가/사무실 탭을 공통 layout으로 구성
  • 지도에 가격 말풍선(CustomOverlay), 마커 클릭 시 목록 카드로 자동 스크롤
  • 최신순 · 가격순 정렬, 가격을 7억 8,000만원 형식으로 변환

검색 — 검색어 강조 표시

  • 검색어를 URL(/search?q=)에 담아 새로고침 · 공유 · 뒤로가기 유지
  • 제목 · 주소 · 설명 · 건물유형을 .or() + ilike로 한 번에 검색
  • 정규식 split으로 일치 부분만 <mark> 처리, 특수문자 이스케이프

매물 상세 — /product/[id]

  • 서버 컴포넌트에서 데이터 조회, 없는 매물은 notFound()
  • Swiper 갤러리(키보드 이동, N / M 카운터), 모바일 · PC 반응형

매물 등록 · 수정 — 하나의 폼 재사용

  • propertyId 유무로 등록/수정 모드 전환, 본인 매물만 수정(owner_id 조건)
  • 주소가 바뀐 경우에만 좌표 재계산, 이미지 Storage 업로드
  • 집주인 · 공인중개사 역할(role)에 따라 메뉴 노출

5트러블슈팅

① 한글 파일명 이미지 업로드 시 400 에러

문제
매물 사진 업로드 중 Supabase Storage가 400 Bad Request 반환
원인
한글 · 공백이 들어간 원본 파일명을 그대로 저장 경로(key)로 사용
해결
crypto.randomUUID() + 확장자로 파일명을 새로 만들어 업로드 → 이름 중복 문제도 함께 해결

② 상세 페이지에서 뒤로 가기 하면 슬라이드 카드가 늘어남

문제
처음 진입 시엔 정상인데, 상세 → 뒤로 가기 후 카드 너비가 깨짐
원인
클라이언트 이동 시 CSS 로드 순서가 바뀌어, 우선순위가 같은 Swiper 기본 스타일이 내 스타일을 덮어씀
해결
.property-swiper .swiper-slide처럼 부모 클래스로 범위를 지정해 우선순위를 높임 (퍼블리싱 경험으로 원인 추적)

③ 네이버 로그인 "Email link is invalid or has expired"

문제
Supabase가 네이버를 기본 지원하지 않아 직접 연동했는데 세션 생성이 실패
원인
서버에서 만든 매직링크 토큰을 맞지 않는 type으로 검증
해결
Route Handler에서 admin.generateLink로 토큰 발급 → verifyOtp({ type: "email" })로 세션 생성. service role 키는 서버 전용 환경변수로 분리
